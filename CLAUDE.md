# Workflow for this fork

This is a personal fork. The owner does not want a proliferation of branches.

- Commit and push directly on `main`. Do not create feature branches.
- Do not open pull requests unless explicitly asked for one.
- This holds even when a session is started with a designated working branch:
  merge into `main` and push there instead.

See AGENTS.md for the project's own development and coding standards.
